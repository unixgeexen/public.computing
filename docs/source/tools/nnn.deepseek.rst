=====================
nnn File Manager Guide
=====================

.. contents:: Table of Contents
   :depth: 3

Introduction
============
``nnn`` is a lightning-fast terminal file manager with full keyboard navigation, disk usage analysis, batch operations, and plugin support. Optimized for performance with minimal resource usage.

Features
========
+--------------------------+-------------------------------------------------------+
| Feature                  | Description                                           |
+==========================+=======================================================+
| **Keyboard Navigation**  | Vim-like hjkl keys, type-to-navigate                  |
+--------------------------+-------------------------------------------------------+
| **File Operations**      | Batch rename, copy/move, delete, archive              |
+--------------------------+-------------------------------------------------------+
| **Plugins System**       | 200+ plugins for custom workflows                     |
+--------------------------+-------------------------------------------------------+
| **Disk Usage**           | Instant analysis with ``^D``                          |
+--------------------------+-------------------------------------------------------+
| **Session Persistence**  | Restore last session on launch                        |
+--------------------------+-------------------------------------------------------+

Installation
============
+---------------------+-------------------------------------------------------+
| Platform            | Command                                               |
+=====================+=======================================================+
| Arch Linux          | ``sudo pacman -S nnn``                                |
+---------------------+-------------------------------------------------------+
| Debian/Ubuntu       | ``sudo apt install nnn``                              |
+---------------------+-------------------------------------------------------+
| macOS (Homebrew)    | ``brew install nnn``                                  |
+---------------------+-------------------------------------------------------+
| From Source         | ``git clone https://github.com/jarun/nnn && cd nnn && |
|                     | make && sudo make install``                           |
+---------------------+-------------------------------------------------------+

Basic Commands
==============
+---------------------+-------------------------------------------------------+
| Command             | Function                                              |
+=====================+=======================================================+
| ``h``/``←``         | Move left                                             |
+---------------------+-------------------------------------------------------+
| ``l``/``→``         | Move right/enter directory                            |
+---------------------+-------------------------------------------------------+
| ``j``/``↓``         | Move down                                             |
+---------------------+-------------------------------------------------------+
| ``k``/``↑``         | Move up                                               |
+---------------------+-------------------------------------------------------+
| ``^D``              | Show disk usage                                       |
+---------------------+-------------------------------------------------------+
| ``Space``           | Select multiple files                                 |
+---------------------+-------------------------------------------------------+
| ``:``               | Open command prompt                                   |
+---------------------+-------------------------------------------------------+

Advanced Keybindings
===================
+---------------------+-------------------------------------------------------+
| Navigation          |                                                       |
+---------------------+-------------------------------------------------------+
| ``g``               | Go to first file                                      |
+---------------------+-------------------------------------------------------+
| ``G``               | Go to last file                                       |
+---------------------+-------------------------------------------------------+
| ``^L``              | Clear/refresh screen                                  |
+---------------------+-------------------------------------------------------+

+---------------------+-------------------------------------------------------+
| File Operations     |                                                       |
+---------------------+-------------------------------------------------------+
| ``d``               | Duplicate file                                        |
+---------------------+-------------------------------------------------------+
| ``R``               | Batch rename                                          |
+---------------------+-------------------------------------------------------+
| ``^P``              | Open plugin menu                                      |
+---------------------+-------------------------------------------------------+

Configuration
=============
+---------------------+---------------------+-----------------------------------+
| Environment Variable| Default             | Description                       |
+=====================+=====================+===================================+
| ``NNN_OPTS``        | (none)              | Startup options                   |
+---------------------+---------------------+-----------------------------------+
| ``NNN_PLUG``        | (none)              | Custom plugin path                |
+---------------------+---------------------+-----------------------------------+
| ``NNN_BMS``         | (none)              | Bookmarked directories            |
+---------------------+---------------------+-----------------------------------+

Example Configuration
---------------------
.. code-block:: sh

   export NNN_OPTS="deE"
   export NNN_PLUG='p:preview-tui;f:fzcd'
   export NNN_BMS='d:~/Documents;w:~/Work'

| ``fzcd``            | Fuzzy directory changer                               |
+---------------------+-------------------------------------------------------+
| ``imgview``         | Preview images                                        |
+---------------------+-------------------------------------------------------+
| ``mimelist``        | Show MIME types                                       |
+---------------------+-------------------------------------------------------+

Troubleshooting
===============
+---------------------+-------------------------------------------------------+
| Issue               | Solution                                              |
+=====================+=======================================================+
| Missing plugins     | Set ``NNN_PLUG`` environment variable                 |
+---------------------+-------------------------------------------------------+
| Slow navigation     | Disable icons with ``-P`` option                      |
+---------------------+-------------------------------------------------------+
| Permission denied   | Run with ``sudo nnn`` or use ``S`` to sudo edit       |
+---------------------+-------------------------------------------------------+
